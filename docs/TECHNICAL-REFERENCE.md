# Technical Reference

## CLI Commands

```powershell
python -m ecommerce prepare --input SOURCE_DIR_OR_ORDERS_CSV --output NEW_PREPARED_DIR
python -m ecommerce analyze --daily PREPARED_DIR/daily.tsv --output NEW_RESULTS_DIR
python -m ecommerce mongo --daily PREPARED_DIR/daily.tsv --database ecommerce_NAME
python -m ecommerce dashboard --results RESULTS_DIR
python -m ecommerce.mongo_profile --database ecommerce_NAME --seller-id SELLER_ID --output REPORT_PATH
```

Output directories must not already exist to prevent accidental mixing of analytical runs.

## Daily Sales TSV Schema

Tab-separated columns without headers:

```text
date  seller_id  orders  revenue_brl  mean_order_brl  peak_order_brl
```

- `date`: YYYY-MM-DD string representing the order purchase date.
- `seller_id`: 32-character hexadecimal string representing the merchant.
- `orders`: Integer count of items sold on that day (>= 1).
- `revenue_brl`: Total sales revenue generated by the seller on that day (R$).
- `mean_order_brl`: Average revenue per item on that day (`revenue_brl / orders`).
- `peak_order_brl`: Maximum single item price sold on that day (R$).

## MongoDB Configuration

The MongoDB importer uses `MONGODB_URI`, defaulting to `mongodb://127.0.0.1:27017`. It requires a dedicated database starting with `ecommerce_` and creates compound index `(seller_id, 1), (year, 1)` and single index `(date, 1)` on collection `daily_sales`.

## Hadoop MapReduce Interface

- `mapreduce/mapper.py`: Reads `daily.tsv` from standard input, emits `seller_id|year \t revenue \t orders \t peak_order`.
- `mapreduce/reducer.py`: Reads sorted key-value pairs, aggregates sums and maxima, and emits `seller_id \t year \t days \t total_revenue \t mean_daily_revenue \t max_daily_revenue \t total_orders \t peak_order_brl`.
