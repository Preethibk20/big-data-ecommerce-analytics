D. Benchmark Results Summary for Viva / Presentation

Theme 1 (MongoDB Indexing Profiling):
- COLLSCAN (Unindexed): 22,973 documents examined, 17 ms execution time.
- IXSCAN (Indexed on seller_id + year): 100 documents examined, 3 ms execution time.
- Result: 229.73x scan reduction ratio, 5.67x query speedup.

Theme 2 (Distributed MapReduce on YARN):
- Input: 69,065 daily seller transaction records (4.28 MB).
- Output: 4,254 aggregated annual merchant summaries across 2 reducers.

Theme 3 (Hive Text vs Columnar RCFile Benchmark):
- Standard Text (daily_text):  4.40 MB HDFS storage,  56.78 s query execution time.
- Gzip RCFile  (daily_rcfile): 937 KB HDFS storage,   50.89 s query execution time.
- Result: 78.71% disk space savings (4.7x compression) & 1.11x query speedup.

E. Troubleshooting & Quick Fixes

Destination DB is not empty Data already ingested! Skip to Part B or drop DB: MongoClient().drop_database('ecommerce_olist')
Failed to read from daily.tsv in HDFS Upload file first: hdfs dfs -put -f /project/data/prepared/ecommerce/daily.tsv /user/root/...
Output directory exists in HDFS Delete before re-running: hdfs dfs -rm -r -f <output-directory>
HDFS Safe Mode is ON Turn off safe mode: hdfs dfsadmin -safemode leave
Docker engine not connected Start Docker Desktop application from Windows Start Menu and wait for whale icon.
Hive warnings (deprecation / SLF4J) Informational only; normal Hadoop Java logging notices. Results remain 100% accurate.
